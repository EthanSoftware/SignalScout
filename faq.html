HELP / FREQUENTLY ASKED QUESTIONS

Quick answers.

Can I search directly in my browser?

Yes. The live scanner calls Open-Meteo's public geocoding service and OpenStreetMap's Overpass API directly from your browser. A modern browser and an internet connection are required. Provider availability and browser cross-origin policies can affect requests.

Do I need Python?

No for browser searches. Python 3.10+ is optional for the CLI and its export workflow. The Python CLI is available in the GitHub repository.

Are returned businesses guaranteed to have working websites?

Results are selected because their OpenStreetMap record contains a website tag. SignalScout does not validate ownership, current availability, or accuracy. The website can be stale or malformed; verify independently.

Why don't I see results for my area?

Mapping coverage varies. Try a nearby place name, a larger radius, another category, or search later if a public endpoint is rate-limited. Browser CORS or network restrictions may block direct requests; the Python scanner is an alternative.

What public information is shown?

Where tagged in OpenStreetMap, a result can include the business name, category, address, website, phone, email, opening hours, and map object link. These fields are optional community submissions.

Does SignalScout save my location or export?

The static website has no SignalScout search backend. Search requests go directly to the named third-party services; JSON/CSV exports download to your device. Your web host may have its own routine logs; see our Privacy Notice.

Can I use the results for marketing?

You are responsible for applicable laws, provider terms, privacy obligations, and respectful use. SignalScout does not provide outreach automation. Review the Terms of Use.

How can I report a bug or contribute?

Open an issue or pull request at EthanSoftware/SignalScout, or contact ethansoftware@outlook.com.
