OPTIONAL LOCAL AUTOMATION

Browser first.
Python when useful.

You can search for free on the homepage without installing anything. For repeatable multi-location research or local exports, run the optional Python tools below.

SINGLE LOCATION

Python scanner

python scanner.py --area "San Jose, California, USA" --category restaurant --limit 30

Writes local JSON and CSV results. Website audits use Google PageSpeed Insights when configured with your own key.

MULTI-LOCATION

Batch automation

python batch_scan.py --areas "Austin, Texas, USA;Portland, Oregon, USA;London, United Kingdom" --category restaurant --limit 30

Search up to 20 places in sequence, with a respectful delay between requests. Results with public website tags sort first. JSON and CSV outputs stay on your machine.

Start locally

git clone https://github.com/EthanSoftware/SignalScout.git
cd SignalScout
python -m http.server 8000

Open http://localhost:8000/ for the browser search. Python 3.10 or newer is required for CLI automation; there are no third-party Python packages.

Public API etiquette

SignalScout uses Open-Meteo and OpenStreetMap public data. Endpoints are independently operated and may limit requests or change terms. Keep batches small, retain attribution, and do not treat public records as verified facts. See methodology and data sources.
