Built for discovery.

Run the Python CLI locally and use the website to configure and review your scan.

Quick start

SignalScout requires Python 3.10 or newer and uses the Python standard library.

git clone https://github.com/EthanSoftware/SignalScout.git
cd SignalScout
python scanner.py --area "San Jose, California, USA" --category restaurant --limit 30

The scan creates leads.json and leads.csv. To use the multi-page website, serve the repository directory:

python -m http.server 8000

Open http://localhost:8000. Run a scan in a second terminal and select “Load / refresh” on the scanner page.

For more Google PageSpeed quota, set the optional PAGESPEED_API_KEY environment variable. Never commit API keys or generated data you intend to keep private.

04 / EXPORT

Portable results

JSON retains scan context and evidence notes; CSV provides a simple tabular export. Treat exports as research data and handle them accordingly.

Responsible research

  • Use documented public interfaces and respect provider policies, quotas, attribution, and rate limits.
  • Do not scrape private areas, bypass access controls, or collect sensitive personal data.
  • Do not automate unsolicited outreach using SignalScout.
  • Manually verify listings and website observations before acting on them.
  • A missing OpenStreetMap website field is not evidence that a business has no website.
  • Keep locally generated exports private unless you intentionally choose to publish them.
