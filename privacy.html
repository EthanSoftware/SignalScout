POLICIES / PRIVACY

Privacy notice.

Last updated: November 12, 2026

This notice explains the intended data flow for the SignalScout static website and open-source Python scanner. The site is published at signalscout.wasner.app by Ethan Software.

Website use

The static pages do not provide user accounts, forms, or a SignalScout-operated scan backend. The scanner page's command-copy controls operate in your browser. The page loads a local leads.json file only when you choose to refresh; when running locally, that file is served by your own local web server. Your hosting provider may independently process standard server logs under its own policies.

Python scanner and third parties

When you run the scanner, your computer sends the requested location to Nominatim, business-data queries to Overpass, and, for listed websites, audit requests to Google PageSpeed Insights. These providers receive information needed to fulfill those requests and handle it under their own privacy policies and terms. An optional PageSpeed API key is supplied by you and should be kept secret.

Generated files

The scanner writes business results to local leads.json and leads.csv files. You control those files and any decision to host, share, or delete them. Do not publish personal or sensitive material inadvertently included in local exports.

Contact

For privacy questions, email ethansoftware@outlook.com.

This notice describes the current intended project behavior, not independent hosting-provider practices. Confirm and update it if deployment, analytics, cookies, or data handling changes.
