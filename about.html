ABOUT THE PROJECT

Useful research,
open by design.

SignalScout is an open-source project by Ethan Software for exploring public local-business listings and their publicly listed web presence.

What it does

Search a place in your browser, query nearby OpenStreetMap features, focus on listings that include a website, inspect available public contact and opening-hour tags, and export results. A Python CLI supports local workflows too.

What it doesn't do

It is not a private business directory, a verification service, a contact-enrichment database, or an outreach automation product. It does not claim that public listing data is complete or accurate.

Maintained by Ethan Software

SignalScout is maintained in public. Review the source, report an issue, or propose a change on GitHub.
