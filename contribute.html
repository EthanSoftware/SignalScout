Help make it better.

SignalScout is built in public. Small improvements to reliability, documentation, accessibility, and responsible data handling are welcome.

View repository ↗Report an issue ↗Contribution guide ↗

Good first contributions

Improve keyboard navigation, add tests for category queries, refine mobile layouts, clarify provider attribution, or fix documentation and accessible labels.

Before opening a pull request

Describe the change and its user benefit. Include manual test steps. Avoid embedding credentials, real user exports, private data, or unsupported claims.

Provider integrations

Propose only services with clear documentation, allowed use, licensing, privacy information, and manageable rate limits. Keep optional sources clearly separate from active integrations.

Stay responsible

No access-control bypass, sensitive personal-data collection, or automated unsolicited outreach. Preserve OpenStreetMap attribution and respect upstream API policies.
