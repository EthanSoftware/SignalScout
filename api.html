Public APIs.

A practical directory of public APIs and open data services related to place discovery and website research. “Active” means SignalScout currently calls the service in its Python scanner; other listings are optional sources and are not represented as integrated product features.

Currently active in scanner.py: Nominatim (geocoding), Overpass API (OpenStreetMap features), and Google PageSpeed Insights (website audits). OpenStreetMap is the underlying open dataset. The other services below are documented options, not live integrations. Provider availability, terms, keys, and quotas may change.

Before integrating an API

Check the provider's current documentation, licensing, attribution, privacy terms, permitted use, rate limits, and credential requirements. A public endpoint is not a promise of unlimited access, production availability, or permission to redistribute its data. SignalScout does not proxy these optional services.
